Collinearity is a linear association between two explanatory variables.

It expresses [[correlation]] specifically between predictor variables.

# definition

collinearity (or [[multicollinearity]] , more specifically) occurs when two or more predictor variables in a multiple regression model are highly [[correlation|correlated]], meaning that one can be linearly predicted from the others with a substantial degree of accuracy. 

Collinearity is a problem in the context of [[multiple regression]] because it undermines the statistical significance of an independent variable.
- *see [[assessing the performance of linear regression]]* 

Unlike [[correlation]], which can be applied more broadly to any two variables, collinearity specifically refers to the predictor variables in the context of a [[Regression]] model.
