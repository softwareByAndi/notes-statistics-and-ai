# definition

**Correlation** refers to any statistical relationship, whether causal or not, between two random variables or bivariate data. It is quantified by correlation coefficients, such as Pearson's correlation, which measures the linear relationship between variables. Correlation values range from -1 to 1, where 1 indicates perfect positive linear correlation, -1 indicates perfect negative linear correlation, and 0 indicates no linear correlation.
