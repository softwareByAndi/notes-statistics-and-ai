The LaTeX formula for the 95% confidence interval about the value of $\hat{\theta}^T X$ is:

$$
\hat{\theta}^T X \pm 2 \cdot \hat{\sigma} \sqrt{X^T (\hat{X}^T \hat{X})^{-1} X}
$$
