### types of variables

- **population**: all data _(all people, etc...)_  
- **sample**: subset of population _(random sample, etc...)_
- **parameter**: numerical summary **of population** _(mean, median, mode, etc...)_
- **statistic**: numerical summary **of sample** _(mean, median, mode, etc...)_

- **quantitative**: numerical data / data that can be measured
    - **discrete**: countable _(number of people, etc...)_  
    - **continuous**: measurable _(height, weight, etc...)_
    - **ratio**: has a true zero _(height, weight, etc...)_
    - **interval**: no true zero _(temperature, days till/since event date, etc...)_

- **categorical**: non-numerical data
    - **nominal**: no order _(hair color, zipcode, ID numbers, etc...)_  
    - **ordinal**: order matters _( [small, medium, large], army ranks, etc...)_
    - **binary**: only two categories _(yes/no, gender, etc...)_

### variable counts

- **univariate**: one variable _(height, weight, etc...)_  

- **bivariate**: two variables _(height and weight, etc...)_
- **multivariate**: more than two variables _(height, weight, and age, etc...)_
